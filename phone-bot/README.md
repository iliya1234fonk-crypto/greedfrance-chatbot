# GreedFrance bot на телефоне

Модератор для RecodeGram: работает как обычный long-polling бот, без IRIS и Docker.

## Запуск / остановка

```sh
sh start.sh          # запустить
sh start.sh stop     # остановить
sh start.sh log      # последние строки лога
```

Сейчас запускается из MargyCode (фоновый процесс). После перезагрузки телефона
или закрытия приложения бота надо поднять заново: `sh start.sh`.

## Команды в чате

- `/help` — список команд
- `/rules` — правила
- `/id` — chat_id, твой id, тип чата
- `/stats` — сообщения в чате, за сегодня, предупреждения
- `/warn` (ответом на сообщение) — предупреждение
- `/unwarn` (ответом) — снять
- `/warns` — у кого есть предупреждения
- `/del` (ответом) — удалить сообщение

Антифлуд: больше 6 сообщений за 10 секунд — сообщение удаляется.
Приветствие: пишет новым участникам группы.

## Чего бот не умеет

Баны, муты, пины. Bot API RecodeGram (`31.77.232.21:2500`) не реализует
`banChatMember`, `restrictChatMember`, `pinChatMessage`, `getChatAdministrators`
и отвечает `METHOD_NOT_FOUND`. Проверить: `python3 tools/check_bot_api.py` в
репозитории `greedfrance-chatbot`.

## Настройки

Токен и адрес API — в начале `bot.py` или через переменные окружения:

```sh
BOT_API_BASE=http://31.77.232.21:2500 BOT_TOKEN=1780243564:... python3 bot.py
```

Состояние (предупреждения, статистика, offset) хранится в `state.json`.

## Важно

Один токен — один опрос. Если одновременно запустить бота на телефоне и
IRIS-версию в Codespace, сервер начнёт отвечать `409 CONFLICT` одному из них.
